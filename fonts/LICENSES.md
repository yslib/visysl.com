- Fira Code 5.3.0 package: `@fontsource/fira-code@5.3.0`. Typeface and packaged font files are licensed under the SIL Open Font License 1.1. Source: <https://www.npmjs.com/package/@fontsource/fira-code/v/5.3.0>.
- VT323 5.3.0 package: `@fontsource/vt323@5.3.0`. Typeface and packaged font files are licensed under the SIL Open Font License 1.1. Source: <https://www.npmjs.com/package/@fontsource/vt323/v/5.3.0>.

The build mounts only the Latin WOFF2 files used by this site from these pinned packages; no font binaries are maintained by hand in the repository.
